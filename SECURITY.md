# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Please do not report vulnerabilities in public issues. Use GitHub's private
vulnerability reporting feature for this repository when available. Otherwise,
contact the project maintainer privately and include the affected version,
impact, and reproduction steps. Do not publish exploit details before a fix is
available.
